# CCN Lab Project (Telecom Operator + B2B)

This repository will host a Cisco Packet Tracer project that models a telecom operator core (OSPF) providing services (DNS/HTTP/FTP/SMTP) and B2B connectivity to two enterprise customers (EIGRP and RIP v2), plus a small RIP v1 + static routing demo segment.
